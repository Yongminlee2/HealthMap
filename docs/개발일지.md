# 개발일지 — 보건소 GIS 지도

2026년 보건소 260곳 기준으로 행정동·법정동·육각 지도를 보건소 단위로 묶어 칠하는 오프라인 단일 HTML 도구.
이 문서는 만든 순서, 중간에 바꾼 결정과 그 이유, 겪은 문제와 해결, 검증 방법을 날짜별로 정리한 기록입니다.
(기능 목록은 [README](../README.md), 변경 요약은 [CHANGELOG](../CHANGELOG.md), 사용자용 설명은 [사용방법.txt](사용방법.txt))

## 목표와 제약
- 서버·설치 없이 **파일 하나(`index.html`, 약 4.4MB)를 더블클릭**하면 동작. 폐쇄망 사용자 → 외부 CDN·외부 요청 0건.
- 기준 데이터: 보건소 260곳 목록(기관코드 8자리)과 보건소↔동 매핑 CSV는 **사용자가 준 것이 정본**. 빌드가 전수 대조하고 어긋나면 중단.
- 작업은 브라우저 `localStorage` 에만 저장(파일 저장 방식은 시험 후 제거), 자동 저장 없음 — 사용자가 [저장]을 누를 때만 이력에 쌓임.
- 메일로 배포: `배포/` 에 압축 파일 + 풀린 폴더(보건소지도.html, 사용방법.txt, 값 입력 양식, 매핑표).

### 데이터
- 행정동: vuski/admdongkor `ver20260701`(통계청 SGIS 가공, CC BY 4.0). 법정동: 국토교통부 법정구역 2023-07(EPSG:5179, EUC-KR → `mapshaper -snap -clean`).
- TopoJSON 으로 단순화(행정동 25%, 법정동 10%) 후 앱이 호(arc)를 한 번만 풀어 경로 문자열로 캐시, 선은 호 단위로 이어 붙임.
- 보건소 이름 정규화 규칙(제N동 ↔ N동, 구분자, 별칭: 안양 8·9동, 대소면→대소읍)을 빌드에 두고, 3,558개 행정동이 모두 배정되는지 검증.

### 속도 이야기 (되돌리지 말 것)
- 처음에는 이동·확대를 CSS transform 으로 밀고 멈추면 다시 그리는 방식으로 14ms 프레임을 얻었으나, **확대 순간 흐려졌다 선명해지는 것이 싫다**는 피드백 → 항상 실제로 다시 그리는 방식으로 되돌림.
- 대신 선 점 수를 배율별 5단계(Douglas–Peucker, 화면 오차 0.6px 이하)로 줄여 속도 확보. 내보내기는 항상 원본 점.
- 측정 시 브라우저 패널이 숨겨지면 프레임이 1~2초씩 튀는 것은 앱이 아닌 측정 환경 문제.

## 2026-10-04 — SHP, 육각 지도, 섬 정리, 편집, 전수 점검
### SHP 저장 · 육각 지도 · 시도 보기 (b188cc1)
- 순수 JS 로 `.shp/.shx/.dbf(CP949)/.prj/.cpg` + zip(STORE, CRC32)을 브라우저에서 직접 생성. QGIS 에서 바로 열림.
- 보건소 단위 합치기는 호를 이어 고리를 만들며 면적 보존을 실데이터로 테스트, mapshaper 로 되읽어 검증.
- 육각 지도: 사용자가 만든 `ko-all.svg` 를 빌드가 내장(육각 그룹 id 260개 = 보건소 코드, 불일치면 빌드 중단). 같은 `#map` 안에서 줌·이동·툴팁·값 입력·내보내기를 공유.
- 시도별 보기(`S.region`): 구역·선 필터, 이미지에 시도 이름.

### 섬 정리 (f7290bc)
- 덩어리를 같은 호를 공유하는 것끼리 묶어 "섬"으로 정의(행정동 1,089개, 법정동 1,891개). 본토·제주도·울릉군(울릉도·독도)은 보호.
- `섬 있음/없음`, 작은 섬 기준, 드래그 사각형 선택 + Delete. 섬이 곧 보건소 전체인 6곳은 '섬 없음'에서 사라지므로 가장 큰 섬을 남기는 규칙(`islandKeep`) 추가.
- 결과는 저장·이미지·SHP 에 반영.

### 육각 정리·SHP, 보기 버튼 (4205e16, d591088)
- 육각도 같은 사각형 선택으로 삭제(제주 6곳·울릉군 보호), 육각 SHP(육각 하나=도형 하나, 좌표계 없음).
- 사용자가 "육각은 왜 안 되냐 / 어떻게 바꾸냐"고 물어서 → 막아 두지 않고 처음부터 지원, 지도 종류는 눈에 보이는 버튼으로.

### 확대 어긋남 점검 (fd2cacf, 5a3b316)
- **원인**: 육각 범위를 화면에 그려진 모양(`getBBox`)으로 재서, 시도 보기로 숨겨 둔 육각은 크기 0 → 전국으로 돌아와도 직전 시도 크기로 확대. 같은 뿌리로 저장본을 불러올 때 낡은 `.cut` 클래스가 범위를 흔들었음.
- **해결**: 범위를 DOM 이 아니라 데이터(육각 좌표 + 지운 목록)로 계산 → 갱신 순서와 무관.
- 그 밖에: 확대·축소 한도를 긴 변 기준으로(세로로 긴 시도에서 축소가 막히던 문제), 보던 시도 밖 보건소 찾기는 전국으로 풀고 이동, 지도 영역 크기 변화를 `resize` + `ResizeObserver` 로 추적.
- 점검 스크립트 `tests/browser-fit-check.js`(85개 조합).

### 전체 점검 2차 (3c10fe1)
- 실제 지도 ↔ 육각 지도 색 동작이 같은지 14,000회 대조(값 입력 4종, 구간 수, 분위수, 팔레트 8종, 색 뒤집기, 구간 색/경계 직접 수정, 자료 없음 색) — 불일치 0.
- 오프라인 확인: 외부 요청 코드 0, 실행 중 요청 0건(정적 스캔 + 실제 열어 확인).
- 찾은 버그 2개: ① 엉뚱한 파일을 올리면 입력해 둔 값이 전부 지워짐 → 하나도 못 맞추면 기존 값 유지. ② 보건소 경계선 색이 육각 지도에 적용 안 됨 → 육각 윤곽에 적용(기본색이면 원본 SVG 색 유지).

### 육각 편집 (7b0665d)
- 요청: 이름을 바꾸면 육각 안 글자도 바뀌게, GIS 편집하듯 육각도 편집.
- 도구 3개: **고르기·삭제** / **옮기기**(끌어서 빈 자리로, 다른 육각 위면 자리 바꿈) / **놓기**(고른 보건소를 빈 자리에, 새 보건소·지운 육각 되살리기).
- 상태: `S.hexPos{id:[dx,dy]}`(SVG 단위 이동량), `S.hexAdd[id]`(새 보건소 육각). 위치·범위는 `placeHex()` 가 원본 꼭짓점 + 이동량으로 계산하고, 소비처(범위·선택·SHP·확대)는 모두 `h.pts/box/d` 만 읽음.
- 놓을 수 있는 자리 = 지금 육각들의 6이웃 중 빈 곳. 끌면 초록(빈자리)/주황(자리 바꿈) 윤곽 미리보기.
- 하나라도 옮기면 원본 SVG 의 시도 경계선·그림자는 맞지 않으므로 숨기고, 이웃 육각과 시도가 다른 변을 다시 그림(`#gHexSido`). 원본과 눈으로 비교해 거의 같음.
- 이름 변경 → 육각 글자: 두 줄 라벨("용인시/처인구")은 새 이름 한 줄로, 원래대로면 복구.

### 육각 편집 전수 점검 (61a665d)
- **무작위 조작 점검**(`tests/browser-fuzz.js`): 조작 약 1,300회를 섞어 돌리며 매 단계 육각 겹침·화면 위치=계산 위치·색 일치·저장 왕복·동 배정 일치를 검사.
- 찾아 고친 버그:
  1. 빈자리 판정이 느슨해 육각이 겹쳐 놓일 수 있음 → 이웃 중심 거리(≈30) 기준 판정 + 놓기 직전 겹침 가드.
  2. 배정표 내보내기→불러오기에서 소속 구역 없는 새 보건소·같은 이름 새 보건소가 사라짐 → 구역 없는 줄을 내보내고, X번호 코드로 그대로 되살림.
  3. 원래 이름으로 되돌린 이름이 '바꾼 이름'으로 남아 육각 글자가 달라짐.
  4. 창이 작아 도구줄이 두 줄이면 팝업이 버튼을 가림 → 도구줄 높이 기준 위치 + 낮은 화면에서는 스크롤.
- SHP(편집 상태) 도형 259개가 화면 위치와 일치함을 직접 파싱해 확인.

## 교훈
1. **화면(DOM) 상태로 계산하지 말고 데이터로 계산한다.** 숨겨진 SVG 요소의 크기는 0, 클래스 갱신 순서에 따라 값이 흔들림 → 육각 확대 어긋남의 뿌리.
2. **기능을 보기별로 막아 두면 사용자는 이유를 묻는다.** 막을 땐 이유를 먼저 알리거나 처음부터 지원.
3. **빌드 통과·테스트 통과 ≠ 동작.** 시작 흐름을 건드리면 페이지를 새로 열어 오류 로그부터 본다(콘솔 로그는 누적되니 이전 오류와 구분).
4. **무작위 조작 점검이 사람이 못 떠올린 조합을 찾는다**(겹침, 왕복 소실).
5. 자동 저장·파일 저장은 사용자가 원치 않았음 — 되살리지 않는다.
6. 합성 마우스 이벤트 시험 팁: `clientX/Y` 는 정수로 반올림되니 사각형 여백은 20 이상, `click` 은 직전 `mouseup` 의 `setTimeout(0)` 이후에 보낸다.
