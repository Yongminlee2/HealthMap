# 보건소 GIS 지도 설계

## 목적
행정동 경계를 보건소 단위로 묶어 전국 지도를 그리고, 보건소별 수치를 범례 구간에 따라 색칠한다.
서버 없이 `index.html` 하나를 더블클릭해서 쓴다(오프라인 동작).

## 결정 사항 (사용자 확정)
- 기준 경계: 2026-07-01 행정동 (vuski/admdongkor `ver20260701`, 원자료 통계청 SGIS, 공공누리 1유형 + CC BY 4.0 → 화면 하단에 출처 표기)
- 보건소 ↔ 행정동 기본 매핑: 시군구(일반구 포함) 1개 = 보건소 1개. 예외(1구 2보건소 등)는 화면에서 행정동 클릭으로 직접 지정하거나 매핑 CSV로 덮어쓴다.
- 법정동 모드는 1차 범위 밖. 매핑 키는 행정동코드(10자리)로 두어 나중에 단위만 늘리면 된다.
- 배경 지도 타일 없음. 보건소 관할 자동 조사 없음.

## 구성
- `tools/build.js` (1회 실행): GeoJSON → mapshaper 위상 유지 단순화 → TopoJSON(양자화) → 기본 보건소 목록·행정동 속성 생성 → `src/app.html` 템플릿에 내장해 `index.html` 출력.
- `src/core.js`: 화면 없는 순수 로직(구간 계산, 색 보간, CSV 파싱, 값↔보건소 매칭). node 테스트 대상이며 빌드 때 html에 그대로 인라인.
- `src/app.html`: 화면(SVG 지도 + 왼쪽 패널 3탭).
- 인라인 라이브러리: topojson-client(경계선 mesh), SheetJS mini(xlsx 읽기/쓰기).

## 화면 동작
- 지도: 행정동 path를 소속 보건소 값 색으로 칠함. 보건소 경계는 `mesh(a!==b)` 굵은 선, 행정동 내부선은 얇은 선(토글). 휠 확대/드래그 이동, 호버 툴팁.
- 데이터 탭: 양식 다운로드(CSV/xlsx; 열: 시도, 보건소명, 보건소코드, 값; 현재 보건소 목록 기준), 업로드(CSV/xlsx), 매칭 실패 행 목록. 매칭 우선순위: 보건소코드 → (시도, 보건소명) → 전국 유일한 보건소명.
- 범례 탭: 구간 수, 자동(등간격/분위수)·직접 입력, 색상표 프리셋 + 구간별 색 수정, 값 없음 색, 제목·단위. 구간 i는 [b(i-1), b(i)) , 마지막 구간만 상한 포함.
- 배정 탭: 보건소 선택 → 행정동 클릭으로 추가/제거, 새 보건소 만들기/이름 변경, 매핑 CSV 내보내기·불러오기(행정동코드, 행정동명, 보건소코드, 보건소명). 편집은 localStorage에 자동 저장.
- 이미지: 제목·범례 포함 PNG(2배)·SVG 저장.

## 검증

- 빌드 스크립트 자체검사: 모든 행정동이 정확히 한 보건소에 배정, 보건소 수·행정동 수 출력.
