# 보건소 GIS 지도

2026년 보건소 260곳 기준으로 행정동(또는 법정동) 경계를 보건소 단위로 묶어 전국 지도를 그리고, 보건소별 수치를 범례 구간 색으로 칠하는 도구입니다.
서버 없이 **`index.html`을 더블클릭**하면 됩니다(인터넷 불필요, 파일 하나만 옮기면 됨, 약 4MB).

## 쓰는 법
1. **데이터 탭** — 양식(CSV/xlsx)을 내려받아 `값` 열을 채워 다시 올립니다. 양식에는 보건소 260곳이 시도·이름·**보건소코드(기관코드 8자리)** 와 함께 들어 있습니다. 코드 → 시도+이름 → 전국에서 유일한 이름 순으로 맞추고, 못 맞춘 행은 목록으로 보여 줍니다. 엑셀에서 저장한 한글 CSV(CP949)도 읽습니다. ("중구보건소"처럼 이름이 겹치면 시도 칸이나 코드가 필요합니다)
   엑셀 없이 하려면 **지도에서 보건소를 클릭**해 값을 바로 넣을 수도 있습니다(편집 모드가 꺼져 있을 때).
2. **범례 탭** — 구간 수, 등간격/분위수/직접 입력, 색상표, 구간별 색, 지도 제목·범례 제목(단위), **경계선 색**(보건소·시도·세부 경계선, 자주 쓰는 색 6가지 또는 직접 선택)을 정합니다.
3. **배정 편집 탭** — 기본 연결을 고칩니다. [선택한 보건소를 지도에서 보기]로 그 보건소 위치로 이동·강조하고, 보건소를 고르고 편집 모드를 켠 뒤 지도에서 구역을 클릭해 옮깁니다. 새 보건소 만들기·이름 변경·배정표 CSV 내보내기/불러오기가 됩니다.
4. 지도 오른쪽 위: **보기 범위**(전국 또는 시도 하나만 잘라 보기, 이미지·SHP도 그 시도만), **＋ / － 확대·축소**, **처음 위치**(확대를 되돌리고 지도를 화면 가운데에 맞춤), **행정동 보기 / 법정동 보기 / 육각 지도 보기**로 지도 종류를 바꿉니다. 육각 지도(`data/hex/ko-all.svg`)는 같은 값·범례·색을 쓰는 또 하나의 보기라서, 한쪽에서 값을 넣으면 다른 쪽에도 반영됩니다(육각 그룹 id가 보건소 코드 260개와 같아서 가능). 육각 지도에서는 구역 배정 편집은 되지 않지만, **[육각 정리]**(드래그로 육각을 골라 Delete로 지움, 제주 6곳·울릉군은 보호)와 **SHP 저장**(육각 하나 = 도형 하나, 그림 좌표라 좌표계 없음)은 됩니다. 법정동 보기에서 한 배정은 법정동 단위로 저장되고(배정표에는 법정동코드가 적힌 줄로 들어감) 행정동 보기에는 나타나지 않습니다. 행정동 보기에서 한 배정은 법정동 보기의 기본값으로 이어집니다.
5. **PNG 저장 / SVG 저장** — 지금 화면(확대 상태, 제목, 범례 포함) 그대로 저장합니다.
6. **SHP 저장**(GIS용 shape 파일, zip) — 보건소 단위로 합친 도형 또는 지금 보는 단위(행정동/법정동) 도형을 내려받습니다. 지금 화면의 배정·값·구간·색이 속성 표에 들어가고, 좌표계 WGS84, 글자 CP949(.cpg 포함)입니다. 합쳐도 면적은 구역 면적의 합과 정확히 같고(테스트로 확인), 다른 GIS 도구(mapshaper)로 다시 읽어 도형·구멍·한글·빈 값을 검증했습니다.
7. **섬 정리**(실제 지도 보기) — 위쪽 [섬 있음/섬 없음]으로 섬을 뺀 지도를 볼 수 있고, [섬 정리]에서 드래그 선택 + Delete로 섬을 직접 지웁니다. 섬 = 같은 경계선을 공유하지 않는 땅덩어리(연결된 덩어리로 판별). 가장 큰 덩어리(본토), 제주 구역의 가장 큰 섬(제주도), 울릉군의 섬(울릉도·독도)은 지울 수 없습니다. 직접 지운 섬은 저장·이미지·SHP에 그대로 반영됩니다(두 보기 층의 경계가 달라 행정동/법정동 보기에서 따로 기억). 섬이 곧 보건소 전체인 곳(옹진·거제·진도·남해·완도·영종구)은 '섬 없음'에서 사라지지 않도록 가장 큰 섬을 남기는 보호 옵션이 기본으로 켜져 있습니다.
8. **육각 정리 / 육각 SHP**(육각 지도 보기) — 위와 같은 방식으로 육각을 드래그로 골라 지웁니다. 지운 육각은 저장·이미지·SHP에 반영되고, 하나라도 지우면 뒤쪽 그림자 윤곽을 함께 뺍니다(그림자가 육각 하나하나가 아니라 전체 윤곽 도형이라서). 육각 SHP는 `.prj` 없이 저장합니다(좌표계가 없는 그림 좌표). 육각 정리를 시험한 결과 선택·삭제·보호·SHP(도형 수, 값, 색)가 화면과 일치함을 다른 GIS 도구로 다시 읽어 확인했습니다.

시도 경계(굵은 검정선)는 "시도 경계" 체크로 켜고 끕니다. 배정을 바꿔도 시도 경계는 그대로입니다.

## 저장과 이력 (브라우저에 쌓기)
- **자동으로 저장되지 않습니다.** 위쪽 **[저장]**(또는 Ctrl+S)을 누를 때만 그때 상태(값·범례·배정·경계선 색)가 이력에 한 건 쌓입니다. 이름을 붙여 저장할 수도 있습니다.
- **저장·이력 탭**에서 이력을 보고 **불러오기**(그때 상태로 복원), **삭제**, **처음 상태로 초기화**를 할 수 있습니다. 초기화·불러오기·배정표 불러오기처럼 지금 작업을 덮어쓰는 동작 전에, 저장하지 않은 작업이 있으면 먼저 저장할지 묻습니다.
- 저장하지 않아도 작업 중인 내용은 새로고침하면 그대로 남습니다(이 브라우저의 임시 보관). 이력에는 [저장]한 것만 쌓입니다.
- 이력은 이 브라우저의 저장소(localStorage)에 있어서 별도 폴더·파일이 필요 없습니다. 대신 **브라우저 데이터를 지우거나 다른 브라우저·PC에서 열면 보이지 않습니다.** 옮기거나 따로 보관하려면 배정 편집 탭의 **배정표 내보내기**(CSV)를 쓰세요.

## 보건소와 행정동은 이렇게 이어져 있습니다
- **`보건소_행정동_매핑표.xlsx`**(이 폴더)에서 엑셀로 확인할 수 있습니다. 시트: ① 행정동별(행정동 3,558개가 어느 보건소인지) ② 보건소별(보건소 260곳과 소속 행정동 목록) ③ 법정동별(5,065개) ④ 확인필요. 첫 시트(행정동별)의 보건소코드·보건소명 열을 엑셀에서 고쳐 **배정 편집 탭 → 배정표 불러오기**로 올리면 지도에 그대로 반영됩니다. 이 파일은 `node build.js`를 돌릴 때마다 새로 만들어집니다.
- 보건소 목록은 `data/centers_2026.tsv`(2026년 260곳, 기관코드 포함), 보건소별 소속 동은 `data/centers_dong_map_2026.tsv`(사용자 제공 매핑 파일을 UTF-8로 옮긴 것, 3,558개)가 **기준**입니다.
- `node build.js`는 이 매핑 파일과 행정동 3,558개를 동 이름으로 전수 대조하고, 하나라도 다르면 **빌드를 멈춥니다**(2026-10 기준 전부 일치). 코드의 시군구=보건소 규칙은 초안일 뿐이고 이 대조가 최종입니다.
- 매핑 파일을 새로 받으면 `data/centers_dong_map_2026.tsv`(열: pbhlth_code, wghtval_dong_nm)만 바꾸고 다시 빌드하세요. 파일은 "망원제1동"처럼 숫자 앞에 '제'를 붙이는 등 표기가 경계 자료와 달라서, 대조 때 '제'·가운뎃점(·)·마침표를 무시합니다. 같은 동의 이름이 바뀐 것(안양 안양8동→명학동 등)은 `tools/build.js`의 `ALIAS`에 적습니다.
- 화성시 효행구(2026-02 신설) 지역은 제공 매핑 기준으로 봉담읍·매송면·비봉면이 만세구보건소, 기배동·정남면이 병점구보건소입니다. 인천 서구보건소는 7월 분할 후 서해구를 맡습니다.
- 엑셀(`보건소_행정동_매핑표.xlsx`)이 열려 있으면 빌드가 `..._최신.xlsx`로 따로 저장합니다. 엑셀을 닫고 다시 빌드하면 원래 이름으로 저장됩니다.


## 경계 자료와 최신화
| 자료 | 기준일 | 로그인 |
|---|---|---|
| 행정동 | 2026-07-01 (vuski/admdongkor, SGIS 원자료) | 필요 없음 |

| 최신(2026) 법정동 shp | — | **V-World(vworld.kr) 또는 국가공간정보포털(NSDI) 로그인 필요** |

법정동은 경계 자체가 거의 바뀌지 않아 2023 자료를 쓰되, 각 법정동이 어느 행정동에 속하는지는 2026 행정동 기준으로 연결했습니다(겹치는 면적이 가장 큰 행정동). 최신 법정동 shp 를 받으면 `data/emd/emd.shp`(+dbf, shx, 가능하면 prj)로 넣고 아래처럼 다시 만드세요. 필드명이 `EMD_CD`, `EMD_KOR_NM`이 아니면 `tools/build.js`의 `-filter-fields`·`-rename-fields` 줄을 맞추고, 좌표계가 UTM-K(EPSG:5179)가 아니면 `-proj` 줄을 고치세요.

```bash
cd tools && npm install          # 최초 1회
curl -L -o ../data/hjd_20260701.geojson https://raw.githubusercontent.com/vuski/admdongkor/master/ver20260701/HangJeongDong_ver20260701.geojson
# 새 행정동 버전이 나오면 tools/build.js 맨 위 SRC_DONG 파일명을 바꾼다
node build.js                    # → ../index.html, data/*.topo.json, data/exceptions_report.txt
node ../tests/core.test.js       # 로직 테스트
```
원본 shp·geojson(수십 MB)은 저장소에 넣지 않았습니다(`data/emd/`, `data/*.geojson`).

## 알아둘 점
- 범례 구간은 `하한 이상 상한 미만`, 마지막 구간만 상한 포함입니다. 범위 밖 값은 맨 끝 구간 색으로 칠합니다.
- 2026-07 전남광주 통합·인천 구 개편·화성 구 신설이 행정동 자료에 반영돼 있습니다. 예전 시군구 코드로 만든 값 파일은 보건소코드가 맞지 않으니 이번 양식을 쓰세요.
- 엑셀 `.xls`(구형)는 읽지 못합니다. xlsx나 CSV로 저장해 올리세요.
- 속도: 확대·이동 중에도 지도를 항상 선명하게 다시 그립니다(흐려졌다 선명해지는 단계 없음). 대신 경계선의 점 수를 화면 배율에 맞춰 줄이고(전국이 한눈에 보일 때는 화면에서 0.6px 이하 차이만 생기도록 5단계), 보건소는 동마다 따로 칠하지 않고 보건소별로 합쳐 칠합니다. 값·범례만 바꿀 때는 경계를 다시 만들지 않습니다. 저장하는 이미지·SVG는 항상 원본 점으로 만듭니다.

## 배포본(메일로 보내는 압축 파일) 만들기
```bash
cd tools && node build.js && python make_dist.py     # → 배포/보건소지도_배포본_날짜.zip (약 1.4MB)
```
압축 파일 안에는 `보건소지도.html`(이것 하나로 동작), `사용방법.txt`(받는 사람용 안내, 원본은 `docs/사용방법.txt`), `보건소_값입력_양식.xlsx`(빈 양식), `보건소_행정동_매핑표.xlsx`가 들어갑니다. 받는 사람은 압축을 풀고 html을 크롬/엣지로 열면 됩니다. 일부 회사 메일은 html이 든 압축 파일을 막으니, 막히면 공유 폴더·메신저 등으로 전달하세요.
