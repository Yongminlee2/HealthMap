# 보건소 GIS 지도

2026-07-01 기준 행정동 경계를 보건소 단위로 묶어 전국 지도를 그리고, 보건소별 수치를 범례 구간 색으로 칠하는 도구입니다.
서버 없이 **`index.html`을 더블클릭**하면 됩니다(인터넷 불필요, 파일 하나만 옮기면 됨).

## 쓰는 법
1. **데이터 탭** — 양식(CSV/xlsx)을 내려받아 `값` 열을 채우고 다시 올립니다. 보건소코드 → 시도+이름 → 전국 유일 이름 순으로 맞추고, 못 맞춘 행은 목록으로 보여 줍니다. 엑셀에서 저장한 한글 CSV(CP949)도 읽습니다.
2. **범례 탭** — 구간 수, 등간격/분위수/직접 입력, 색상표, 구간별 색, 지도 제목·범례 제목(단위)을 정합니다.
3. **배정 편집 탭** — 기본은 "시군구 1개 = 보건소 1개"입니다. 1구 2보건소 같은 예외는 보건소를 고르고 편집 모드를 켠 뒤 지도에서 행정동을 클릭해 옮깁니다. 새 보건소 만들기·이름 변경·배정표 CSV 내보내기/불러오기가 됩니다.
4. 지도 오른쪽 위 **PNG 저장 / SVG 저장** — 지금 화면(확대 상태, 제목, 범례 포함) 그대로 저장합니다.

편집한 배정·값·범례는 브라우저에 자동 저장됩니다(다른 PC로 옮길 땐 배정표 CSV를 쓰세요).

## 알아둘 점
- 범례 구간은 `하한 이상 상한 미만`, 마지막 구간만 상한 포함입니다. 범위 밖 값은 맨 끝 구간 색으로 칠합니다.
- 기본 매핑이 실제 관할과 다를 수 있는 곳(인천 신설 4개 구, 화성 신설 4개 구, 1구 2보건소 등)은 `data/exceptions_report.txt`에 정리돼 있습니다. 확인 후 배정 편집 탭에서 고치세요.
- 2026-07 전남광주 통합으로 시군구 코드가 바뀌었습니다. 예전 코드로 만든 값 파일은 시도+이름으로만 붙습니다.
- 법정동 단위 보정은 아직 없습니다(배정 키가 행정동코드 10자리라 나중에 단위만 늘리면 됩니다).
- 엑셀 `.xls`(구형)는 읽지 못합니다. xlsx나 CSV로 저장해 올리세요.

## 다시 만들기 (경계 데이터 갱신)
```bash
cd tools && npm install          # 최초 1회
# data/ 에 새 행정동 GeoJSON 을 받고 tools/build.js 맨 위 SRC 파일명을 바꾼 뒤
curl -L -o ../data/hjd_20260701.geojson https://raw.githubusercontent.com/vuski/admdongkor/master/ver20260701/HangJeongDong_ver20260701.geojson
node build.js                    # → ../index.html, data/exceptions_report.txt
node ../tests/core.test.js       # 로직 테스트
```
